# Shoot moments

> 我记得一个情节 → 它在哪一集，从几分几秒开始。

Person of Interest 里 Root 和 Shaw 的场景索引。你记得一场戏，想不起来在哪集，
这里可以查到集数、起止时间，还有那场戏的台词。

**<https://shoot5313.github.io/shoot-moments/>**

## 里面有什么

134 条，1040 行台词，加起来 146 分钟，覆盖 51 集。每一条都从字幕逐句核对过。

可以按三条线分开看：Root × Shaw、Root 个人线、Shaw 个人线。
记得半句台词就直接搜，想不起来关键词的时候按场景浏览。

## 时间戳基准

所有时间按 `HDTV.x264-LOL` 版字幕算。别的片源一般整体差一个固定偏移，
对齐一场戏就能推出其他的。
