# Shoot moments

> 我记得一个情节 → 它在哪一集，从几分几秒开始。

Person of Interest 里 Root × Shaw 的场景索引。不是剧情百科，也不是字幕全文搜索，
只解决一件事：**记忆中的情节 ↔ 精确剧集位置**。

**<https://shoot5313.github.io/shoot-moments/>**

## 里面有什么

82 个 moment，613 行台词，加起来 84 分钟，分布在 51 集里。全部从字幕逐条核对过，
没有一个时间戳是估的。

三条线可以分开看：Root × Shaw 的交互、Root 个人线、Shaw 个人线。
想不起来关键词的时候按场景浏览；记得半句台词也能直接搜。

## 时间戳基准

所有时间码基于 **`HDTV.x264-LOL`** 版字幕。字幕时间码跟着发布版本走，
你手上的片源如果是别的版本，可能存在一个固定偏移。
